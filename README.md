# AI IELTS Trainer

An AI-powered website that helps users improve their IELTS score through
personalized practice, progress tracking, and AI feedback.

## Features

- Grammar practice
- Vocabulary review
- Progress tracker
- AI explanations

## Tech Stack

- HTML
- CSS
- JavaScript
- Python

## Project Structure

- /src - Website code
- /prompts - AI contracts
- /docs - Project documentation
